# 學習小夥伴

國小課程的 3D 闖關地圖。第一層是學科島，第二層是每一課的地標，第三層是課程場景，每棟建築是一關。

網址：https://qooiverson3.github.io/learnland/

## 結構

| 路徑 | 用途 |
| --- | --- |
| `index.html` | 遊戲引擎（3D 地圖、題目、帳號、進度） |
| `favicon.ico`、`apple-touch-icon.png`、`icon-512.png` | 網頁與手機主畫面圖示（紅色「學」字印章） |
| `config.js` | Google Apps Script 網址與 TOKEN（repo 裡是空字串，部署時由 Actions secret 產生，見下） |
| `db-gas.js` | 把進度讀寫到 Google 試算表 |
| `content/catalog.json` | 學科與課程目錄 |
| `content/<課程 id>.json` | 每一課的關卡與題目 |
| `apps-script/Code.gs` | 貼到 Google 試算表的後端程式 |
| `tools/validate.js` | 題庫檢查程式 |
| `.github/workflows/pages.yml` | 推到 `main` 時先檢查題庫，通過才部署 |

## 第一次設定

### 1. 開啟 GitHub Pages

repo 的 Settings → Pages → Build and deployment → Source 選 **GitHub Actions**。之後每次推到 `main` 都會自動部署，到 Actions 分頁可以看進度。

### 2. 串接 Google 試算表

1. 在 Google 雲端硬碟建一份新試算表，例如「學習大陸進度」。
2. 「擴充功能 → Apps Script」，把 `apps-script/Code.gs` 整個貼上取代原本內容，儲存。
3. 「專案設定 → 指令碼屬性 → 新增」，名稱 `TOKEN`，值自己取一串英數字。
4. 「部署 → 新增部署作業」，類型「網頁應用程式」，執行身分「我」，誰可以存取「所有人」，部署並授權。複製 `/exec` 結尾的網址。
5. 到 repo 的 Settings → Secrets and variables → Actions，新增兩個 secret：`GAS_URL`（網址）、`GAS_TOKEN`（TOKEN）。**不要把網址和 TOKEN 直接填進 `config.js` 再 commit**——這個 repo 是 public 的，commit 進去等於公開給所有人看。部署時 workflow 會用這兩個 secret 自動產生真正的 `config.js`，repo 裡的 `config.js` 保持空字串即可。
6. 重新推一次 `main`（或到 Actions 分頁手動重跑 workflow），讓新設定生效。

完成後打開網站，登入畫面會顯示「已連上雲端」。試算表會出現三個分頁：

- `進度總表`：每位冒險者每一課一列，含隨堂測驗最佳／最近成績、測驗完成與開始次數、太快答錯的題數
- `作答明細`：每一題第一次是否答對、第一次作答花了幾秒、是不是太快就答錯、重考有沒有答對、開放題寫了什麼
- `測驗紀錄`：每一次隨堂測驗一列（每課保留最近 5 次），含答錯的題目
- `_db`：原始資料，請勿手動修改

## 怎麼確認孩子真的學會

- **答錯就看答案，關卡最後再考一次**：答錯不能繼續亂點，畫面直接顯示正確答案和說明，「下一題」要等幾秒才能按。這一題會排到這關最後，選項順序打亂再考一次。
- **星星只看第一次**：每一題第一次作答就決定有沒有星星，之後重玩不會補星。
- **隨堂測驗**：全部關卡過關後才能考，從整課抽 10 題（開放題除外），每題只能作答一次。獎狀等級看隨堂測驗的最佳成績，可以重考。中途離開不算成績，但「測驗開始次數」會增加。
- **太快答錯**：題目和選項還來不及讀完（約每秒 8 個字，2.5～8 秒）就答錯，會提醒孩子慢慢讀，「下一題」要等 8 秒；連續兩題太快答錯，要等 10 秒。

- **獎章**：每一課全部過關、考完隨堂測驗，就會得到那一課的獎章，依獎狀等級分金、銀、銅。重考考得更好會升級，考差不會降級。點畫面上方的冒險者名稱，可以看到所有課程的獎章收藏；「進度總表」的「獎章」欄也會記錄。

判讀方式：「第一次就答對」看直覺掌握度，「重考答對」看讀完說明後有沒有記住，「隨堂測驗」看整課是否真的學會。「太快就答錯」多的題目，通常是猜的。

修改 `Code.gs` 後，要到「部署 → 管理部署作業 → 編輯 → 版本選新版本」，網址不變，新程式才會生效。

## 新增課程

在 Claude 用 `learnland-lesson` skill：附上課本照片，說「加進學習小夥伴」。新的課程檔放進 `content/`、更新 `content/catalog.json`，推到 `main` 即可。CI 會檢查題庫格式，並比對上一版，避免已發布的題目編號被更動。

## 注意

- 免費方案的 GitHub Pages 需要 public repo，這裡的題目任何人都看得到；Apps Script 網址和 TOKEN 現在改放在 Actions secret，不會進 git 歷史，但實際打開網站後，瀏覽器的開發工具（Network、原始碼）還是看得到明碼傳送的 TOKEN。TOKEN 只能擋掉隨便亂打網址的人，不是真正的密碼，被看到也只要在 Apps Script 換一個新的、更新 secret 即可。
- 題目引用了課本內容，請只給家人使用。網站已設定不讓搜尋引擎收錄，但知道網址的人仍然打得開。
- 冒險者名稱沒有密碼，知道名稱的人可以接著玩那個帳號。
